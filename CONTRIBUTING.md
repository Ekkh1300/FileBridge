# Contributing

Thanks for looking at FileBridge! It is a small, self-contained project and contributions are very welcome.

## Ground rules

- **Keep it LAN-only.** No outbound network calls, no telemetry, no third-party services — that is the whole point of the app.
- **No new runtime dependencies** in the server unless there is a very good reason. It currently ships with Fastify, `@fastify/websocket`, `@fastify/static`, `qrcode` and Node's built-in `node:sqlite`.
- **Keep the client dependency-light** (React + Vite + Tailwind only).

## Getting started

```bash
git clone https://github.com/Ekkh1300/FileBridge.git
cd FileBridge
npm install
npm run build      # build the client
npm start          # run the server on :3000
npm run dev        # server + Vite with hot reload
```

Node.js **22.5 or newer** is required (`node:sqlite`).

## Tests

```bash
node server/test/smoke.mjs
```

The suite starts a server, drives it with two independent cookie jars and asserts 36 behaviours: pairing, cross-session isolation, WebSocket realtime events, chunked upload, byte-identical download, magic-byte sniffing, path-traversal rejection, chunk ownership, revocation, upload resume, session end and disk cleanup.

Please add an assertion for every bug you fix and keep the whole suite green.

## Building the Windows executable

```bash
npm run exe        # -> release/FileBridge.exe + release/FileBridge-Portable.zip
```

`tools/build-exe.mjs` bundles the server with esbuild and packages it with pkg (the Node runtime is included). The icon is generated by `tools/make-ico.mjs` — no binary assets are committed.

## Style

- 2-space indentation, single quotes, semicolons — same as the existing code.
- Small, focused commits with a clear message.
- Comments explain *why*, not *what*.
- Keep the UI copy in English and the documentation (README) bilingual: English first, Persian below.

## Reporting bugs

Open an issue with the browser/OS, the steps to reproduce and what you expected to happen. If it involves the network path (phone ↔ PC), mention whether both devices are on the same Wi‑Fi and whether the firewall allowed the app.
